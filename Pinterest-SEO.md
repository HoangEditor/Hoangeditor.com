## 6. RICH PINS SETUP

### Cài đặt Rich Pins cho Articles:
1. Vào [Pinterest Rich Pin Validator](https://developers.pinterest.com/tools/url-debugger/)
2. Nhập URL bài blog bất kỳ, ví dụ: `https://hoangeditor.com/blog/posts/scale-video-business.html`
3. Xác nhận Open Graph meta tags đã có (bài blog đã có `og:title`, `og:description`, `og:image`)
4. Apply để được duyệt — Rich Pins tự động hiển thị tiêu đề + mô tả phong phú hơn

> **Lưu ý:** Mỗi bài blog đã có schema `BlogPosting` JSON-LD + Open Graph tags → tương thích Rich Pins.
