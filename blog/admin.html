Cài Đặt API

Cấu hình nhà cung cấp AI để bật tạo blog một chạm.

Lấy khóa tại platform.deepseek.com. Chỉ lưu trong trình duyệt của bạn.
Mặc định: DeepSeek. Cũng hoạt động với endpoint tương thích OpenAI.

Cách hoạt động

Với khóa API DeepSeek: Enter a topic → click Tạo → AI writes the full post automatically. DeepSeek-V3 costs ~$0.27/1M input tokens — about 100 blog posts for a few cents.
Không có API key: Enter a topic → click Tạo → copy the prompt → paste into ChatGPT/Claude/DeepSeek → paste the JSON response back.

Tự Động Deploy Lên GitHub

Đăng bài trực tiếp lên GitHub. Cloudflare Pages tự deploy khi push — không cần tải file thủ công.

Tạo tại github.com/settings/tokens — chỉ cần quyền repo.
